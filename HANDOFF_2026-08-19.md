## Important LINE distinction

There are two different things that the user may call “LINE OA notification”:

1. **Server push to a staff LINE destination** (`LINE_ORDER_NOTIFY_TO`): reliable and independent of the customer's phone. This produces a LINE push to the configured personal user/group.
2. **A new inbound conversation item in LINE Official Account Manager**: this requires the customer to send into the OA chat (for example via `liff.sendMessages`). An OA cannot push a message to its own OA inbox.

Production `LINE_ORDER_NOTIFY_TO` was previously observed to be the same personal LINE user used for testing. Do not expose its value. If the shop wants a separate operational destination, use a staff LINE group ID beginning with `C...`; invite the OA, type `id`, and use the returned group ID in Vercel. Do not change Production environment variables without explicit authorization.
